## What Is Dreadfall?

Dreadfall turns the Commonwealth into a horror game. It is a compact list of roughly **116 enabled mods**, plus the Creation Club content and DLC that come with the Anniversary Edition (172 Creation Club entries and 6 DLC). Because it is smaller than most big modlists, it is easier to learn and tends to be lighter to run.

At a glance, it focuses on:

- **Atmosphere**: a dark ENB (Real-Force), new weather, heavy ambient sound, and a creepy audio overhaul
- **Horror quests and locations**: haunted houses, cemeteries, sewers, and a Vault gone wrong
- **New and scarier creatures**: changed ghouls, floaters, centaurs, spiders, and more
- **Tougher combat**: Damn Apocalypse, True Damage, SCOURGE, and MAIM Redux
- **An alternate start**, plus a rebuilt interface (FallUI)
- **Stability fixes** and a modern framework stack

Dreadfall does not include Sim Settlements 2 or a settlement overhaul. This is a list about exploring and surviving, not building.

## Content Warning

This list is made to be unsettling. Expect:

- **Jump scares** and sudden loud sounds
- **Disturbing creatures** and altered ghouls
- **Gore**, including head explosions and similar effects (Gibs of Glory)
- **Dark, intense atmosphere** in many interiors and at night

If you are sensitive to any of this, play with the lights on, keep the volume reasonable, and take breaks. Headphones make it much scarier, so use them only if you want that.

## Before You Install

### Requirements

- **Fallout 4 on Steam**, with a **clean install**
- **All DLC and Creation Club content** that comes with the Anniversary Edition update. The list includes every Creation Club item and all six DLC packs (Automatron, Contraptions Workshop, Far Harbor, Nuka-World, Vault-Tec Workshop, and Wasteland Workshop). Wabbajack reports them as missing if you do not own them.
- **Wabbajack** and a **Nexus Mods account**. A Nexus Premium membership makes downloading much faster. Without it, you must click through each download manually.
- **Free disk space** for the 4K textures and LOD.

### Do a clean install of Fallout 4

Old mods and leftover settings are the number one cause of broken modlist installs. To start fresh:

1. **Uninstall** Fallout 4 from Steam.
2. **Delete the game folder** manually, for example `Steam\steamapps\common\Fallout 4`.
3. **Delete your documents folder for the game**: `C:\Users\<you>\Documents\My Games\Fallout4`. This removes old saves and INI files.
4. *(Optional but recommended)* Delete `C:\Users\<you>\AppData\Local\Fallout4`.
5. **Reinstall** Fallout 4 from Steam.
6. **Launch the game once** and let it reach the main menu, then close it. This creates fresh INI files and lets Wabbajack find your game.

> **Tip:** Make sure every AE DLC and Creation Club item has finished downloading in Steam before you start Wabbajack.

## Installing the List

> The steps below are the standard Wabbajack process. Where the list's own page gives different instructions, follow the page.

1. **Download Wabbajack** from the official site and place `Wabbajack.exe` in its own folder in a simple location, such as `C:\Wabbajack`. Avoid protected folders like `Program Files` and `Desktop`.
2. **Download the Dreadfall** `.wabbajack` file from the list's download page.
3. Open Wabbajack and choose **Load a Modlist from Disk**, then select the `.wabbajack` file.
4. Choose **install** and **download** locations on a drive with plenty of space. Use short paths such as `C:\Modlists\Dreadfall`.
5. Click **Install** and wait for it to finish.
6. If Wabbajack reports **failed downloads** at the end, download them manually into your downloads folder and **run the install again**.
7. When it finishes, open the install folder and run the **MO2 executable** for the list.

## Your First Launch

1. In MO2, open the executable drop-down next to the **Run** button and select **F4SE** (Fallout 4 Script Extender). **Always launch the game this way**, never directly from Steam.
2. Click **Run**.
3. The list includes **Start Me Up (Alternate Start and Dialogue Overhaul)**. This changes how a new game begins, so expect a different opening from vanilla. Read the prompts carefully and take your time at this stage.
4. Open the **MCM** (Mod Configuration Menu) from the game's settings or pause menu to adjust mod options.
5. For your first session, change as little as possible. Play a while with the defaults before you start tweaking.

> **Reminder:** Start a new game for each new playthrough. Do not add or remove mods in the middle of a save.

## What's in the List

A quick tour of the main groups. The full load order is visible in MO2's left pane, organized by separator.

### Core fixes and frameworks

F4SE, Unofficial Fallout 4 Patch (UFO4P) and its Creations bundle patches, Previsibines Repair Pack (PRP), Addictol and Addictol Crash Logger, Address Library, Baka Framework, RobCo Patcher, Runtime Database, Community Fixes Merged, Weapon Debris Crash Fix, High FPS Physics Fix, Canary Save File Monitor, and the MCM tools (Mod Configuration Menu, MCM Booster). Also in this group are Random Encounter Framework, Holy Framework, Base Object Swapper, and Immersive Animation Framework. These keep the game stable and power the rest of the list.

### Environment and visuals

**Real-Force ENB**, Native Weathers, Whispering Hills, the Vivid Fallout texture set (4K, with parallax and a puddle remover), Commonwealth LOD (4K), 4K Textures, and Pip-Boy Flashlight. Together these give the dark, cold, and grim look.

### Audio

Reverb and Ambiance Overhaul, Sinister Ambient Sound, Numbers Stations (Ghosts of the Commonwealth), Terrifyer (Ghouls), Horrorghouls soundpack, and Scary Clown Monkey Trap HD.

### Creatures

Project NEMEAN, CRITTERS, Mutant Menagerie, The Famished, The Haunting, Rad Spiders, Lamprey Floaters, Capital Wasteland Centaurs, Institute Centaurs, Worldwide Ghouls, C Horror Ghoul, Commonwealth Encounter Pack, Gibs of Glory, and the Feral Ghoul Bite and Deathclaw Grab skills.

### Gameplay

Damn Apocalypse (Combat, Power Armor, Loot, and Core Resources), True Damage, SCOURGE, MAIM Redux, Lore Friendly Names, Scaling Flag Remover, Portable Junk Recycler Mk 2, Radiation Removers, and Remember Lockpick Angle.

### User interface

The **FallUI** suite (HUD, workbench, icon library, confirm boxes, sleep and wait), FIS (the FallUI item sorter), M8r98a4f2's Complex Item Sorter, HUDFramework, and Condition Boy.

### Dogmeat

K-9 Harness, Dogmeat Lags Behind, Pet - Call - Feed Dogmeat, ADOGCALYPSE, and Everyone's Best Friend. See [Dogmeat and Companions](#dogmeat-and-companions).

## Surviving the Dread: Gameplay Tips

- **Expect a harder game.** Damage-related mods (True Damage, MAIM Redux, SCOURGE, and the Damn Apocalypse combat module) change how fights work. Enemies and you can both go down fast. Learn the rules in the MCM and in your first few fights.
- **Use cover and fight smart.** Rushing into a room is a good way to die. Peek, listen, and retreat.
- **Listen carefully.** The audio mods are part of the gameplay. Sound is often your first warning.
- **Watch your light.** The list uses a dark ENB and weather. Keep your **Pip-Boy Flashlight** handy at night and underground.
- **Save often, and use multiple files.** Rotate through several saves instead of overwriting one. The list includes **Canary Save File Monitor** to help watch for save problems.
- **Manage your inventory.** The UI includes item sorters and the Portable Junk Recycler Mk 2, which help you stay organized. Loot is also affected by the Damn Apocalypse loot module, so check the MCM to see how it works.
- **Retreat is allowed.** Some creatures, such as deathclaws, have grab skills, and feral ghouls can bite and cause problems. Do not be afraid to run.
- **Check the MCM before blaming the list.** Many difficulty options can be adjusted without editing files.

## Dogmeat and Companions

Dreadfall has several Dogmeat mods working together, so he is more useful than in vanilla:

- **K-9 Harness** gives him tactical armor and a backpack.
- **Dogmeat Lags Behind** and **Pet - Call - Feed Dogmeat** change how he follows you and how you interact with him.
- **ADOGCALYPSE** edits Dogmeat's behavior and stats.
- **Everyone's Best Friend** lets him travel with you alongside a human companion without console commands.

Check the MCM for each of these to see what is configurable. A companion at your side is a real comfort when things get dark.

## Performance and Stability Tips

- **Always launch through F4SE in MO2**, never through Steam.
- **Do not change graphics settings blindly.** The list ships with its own tuned settings and an ENB.
- **Lower ENB or texture quality if you struggle.** Turning down ENB effects is the first thing to try on a weaker PC.
- **Close other heavy programs.** Browsers, overlays, and recording software take memory the game needs.
- **Use the crash logger.** The list includes **Addictol Crash Logger**. If the game crashes, keep the log handy when asking for help.
- **Do not enable or disable mods mid-save.** This can break scripts and saves. Make changes only before starting a new game.

## Troubleshooting

| Problem | What to try |
|---|---|
| Wabbajack cannot find the game | Launch Fallout 4 once from Steam and make sure it is installed cleanly. Re-run Wabbajack. |
| Wabbajack says AE or DLC files are missing | Confirm all AE DLC and Creation Club content is installed and fully downloaded in Steam, then re-run the install. |
| Downloads failed at the end of install | Download the listed files manually into your downloads folder and run the install again. |
| Wabbajack will not launch | Place it in a simple folder such as `C:\Wabbajack`, outside protected folders. |
| Game will not start | Make sure you are launching **F4SE** from MO2 and not the regular game executable. |
| The game looks too dark | Dark is intended. Use your flashlight, and see the ENB and brightness options before changing anything else. |
| A quest will not start | Check the quest mod's page for its start conditions, and make sure its requirements (such as Far Harbor for Huntress Manor) are met. |
| Random crashes | Read the Addictol crash log and share it when asking for help. Also check that you did not add mods or change the load order. |

## Updating and Adding Your Own Mods

- **Check the changelog first.** Read it before updating the list.
- **Updating can remove files that are not part of the list.** Wabbajack may delete anything outside the modlist, so back up anything you added.
- **Start a new character after major updates.** Mid-playthrough updates can break saves.
- **Adding mods is at your own risk.** The list is a balanced load order. If a new mod causes problems, remove it before asking for support.
